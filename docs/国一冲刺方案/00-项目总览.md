# 智慧大棚物联网平台 - 国一冲刺总体方案

> **版本**：v1.0  
> **制定日期**：2026-06-30  
> **目标赛事**：世界职业院校技能大赛 - 新一代信息技术赛道

## 一、项目定位

### 一句话介绍
> 一套能让大棚自己思考的智慧农业系统——端边云架构 + 数字孪生 + AI赋能，让农民躺着就能把菜种了。

### Slogan
**慧种田，更轻松**

### 核心价值
- **对农户**：省心、省力、省钱、增产
- **对评委**：技术有深度、展示有冲击、创新有亮点

## 二、最终方案确认（5+1架构）

| 序号 | 模块 | 技术实现 | 对应评分项 | 状态 |
|:----:|:-----|:---------|:----------|:----:|
| 1 | **双棚物理沙盘** | A棚番茄 + B棚生菜 + 气象站，120×60cm底座 | 任务难易度 | ✅ 确认 |
| 2 | **数字孪生3D大屏** | Three.js双棚3D模型，与真实沙盘实时联动 | 技术先进性 | ✅ 确认 |
| 3 | **端-边-云三层架构** | ESP32感知节点 → RK3588边缘网关 → FastAPI云平台 | 技术先进性 | ✅ 确认 |
| 4 | **多智能体协同** | 气象Agent + 病虫害Agent + 调控Agent | 创新创意 | ✅ 确认 |
| 5 | **边缘AI病虫害识别** | YOLOv8n部署在RK3588，摄像头拍叶→2秒出结果 | 技术先进性 | ✅ 确认 |
| **+1** | **农业知识图谱RAG** | Neo4j图数据库 + 轻量大模型，语音问答 | 创新创意 | ✅ 确认 |

### 明确砍掉的功能
- ❌ 无人机/机器狗（沙盘里演不了）
- ❌ 区块链溯源（展示不出来）
- ❌ 32B大模型（跑不动也没必要）
- ❌ 卫星遥感（不适合沙盘场景）
- ❌ ThingsBoard（用自己的平台才叫技术）
- ❌ 多语言支持（换成方言更接地气）

## 三、技术栈总览

### 软件技术栈
| 层级 | 技术选型 | 说明 |
|------|---------|------|
| 前端 | Vue 3.4 + TypeScript + Vite 5 | 已有基础，继续完善 |
| 可视化 | ECharts 5 + Three.js + Vue Flow | ECharts做图表，Three.js做3D孪生 |
| 后端 | Python 3.11 + FastAPI + SQLAlchemy 2.0 | 已有基础，继续扩展 |
| 数据库 | PostgreSQL 15 + TimescaleDB + Redis + Neo4j | 关系+时序+缓存+图数据库 |
| 消息队列 | EMQX（MQTT 5.0） | 已有基础，设备通信 |
| AI推理 | YOLOv8 + RKNN（边缘）+ FastAPI封装 | 病虫害识别 |
| 知识图谱 | Neo4j + 轻量大模型RAG | 农业知识问答 |

### 硬件技术栈
| 层级 | 技术选型 | 说明 |
|------|---------|------|
| 感知层 | ESP32-WROOM-32 × 8 | 传感器采集+执行器控制 |
| 边缘层 | RK3588S开发板（8GB+256GB） | 边缘计算+AI推理+本地网关 |
| 传感器 | SHT30 + BH1750 + SCD41 + DS18B20等 | 10种，58个 |
| 执行器 | 卷帘电机 + 通风扇 + 电磁阀 + 补光灯等 | 8种，29个 |
| 展示 | 55寸4K大屏 + 7寸触摸屏 | 大屏展示+本地操作 |
| 摄像头 | 海康威视400万POE + USB摄像头 | 视频监控+AI识别 |

## 八、核心记忆点（讲给评委听的）

1. **"端边云三层架构"** — 不是简单的云平台，是有边缘智能的完整体系
2. **"数字孪生虚实联动"** — 手指点大屏，大棚自动转
3. **"三个AI Agent商量着干活"** — 多智能体协同，不是单智能体
4. **"边缘AI病虫害识别"** — 本地2秒出结果，不用传云端
5. **"知识图谱+RAG专业问答"** — 问啥都能答，还能追溯来源
