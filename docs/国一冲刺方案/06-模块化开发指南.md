## 二、新增模块操作指南

### 第一步：后端新增模块

**1. 创建模块目录**
```bash
mkdir -p /workspace/backend/app/modules/新模块名/{api,services,models,schemas}
```

**2. 创建模块API入口** (`modules/新模块名/api.py`)：
```python
from fastapi import APIRouter

router = APIRouter(prefix="/新模块名")

@router.get("/")
async def get_module_info():
    return {"name": "新模块名", "status": "ready"}
```

**3. 在主入口注册** (`backend/app/main.py`)：
```python
# 添加导入
from .modules.新模块名.api import router as 新模块名_router

# 注册路由
app.include_router(新模块名_router, prefix=settings.API_V1_PREFIX)
```

### 第二步：前端新增模块

**1. 创建模块目录**
```bash
mkdir -p /workspace/frontend/src/modules/新模块名/{views,components,api}
```

**2. 创建模块导出入口** (`modules/新模块名/index.js`)：
```javascript
export { default as 页面名 } from './views/页面名.vue'
```

**3. 在路由中注册** (`src/router/index.js`)：
```javascript
import { 页面名 } from '../modules/新模块名'

{
  path: '/新模块名',
  component: Layout,
  children: [{ path: '', component: 页面名 }]
}
```

### 第三步：独立部署（可选）

**后端独立部署**：
1. 复制 `main.py` 为独立入口文件
2. 只保留需要的模块路由
3. 修改端口和配置
4. 通过 MQTT 与主平台通信

**前端独立部署**：
1. 复制项目为独立仓库
2. 修改路由和模块导入
3. 独立构建和部署

## 七、开发流程规范

### 按模块开发原则

1. **独立开发**：每个模块有独立的代码目录，互不干扰
2. **独立测试**：可以单独启动测试，无需部署整个系统
3. **独立部署**：需要时可以打包成独立服务
4. **接口定义优先**：先定义API接口，再实现功能
5. **文档同步**：每个模块的API文档单独维护

### 代码审查要点

- 模块间依赖是否最小化
- 是否使用统一的API响应格式
- 错误处理是否完善
- 日志记录是否规范
- 安全措施是否到位
