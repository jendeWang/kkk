# 智慧大棚物联网平台 - 团队角色及职责

> 说明：四个角色由AI统一调度执行，产品经理（用户）不懂技术和农业，仅在关键决策点参与确认。

---

## 一号：架构师（技术总负责人）

**核心职责**：技术方向把控、方案设计、质量兜底

**具体工作**：
- **架构设计**：负责系统整体技术架构（前端Vue3 + 后端FastAPI + MQTT + PostgreSQL），确保技术选型合理
- **方案评审**：在研发动手前，审核所有功能的技术实现方案，评估风险和性能影响
- **疑难问题攻坚**：研发搞不定的技术难题，架构师接手解决
- **代码质量把关**：核心代码走查，确保可维护性、安全性、性能达标
- **农业知识转化**：将农业场景需求（如大棚环境参数、灌溉策略）转化为技术可实现的功能定义
- **技术债务管理**：识别并规划重构和优化项

**决策权限**：技术方案一票否决权，但需向产品经理解释原因

---

## 二号：产品经理（用户本人）

**核心职责**：需求确认、验收把关、优先级排序

**具体工作**：
- **需求确认**：架构师/研发提出的功能方案，你只需回答"可以/不可以/再想想"，不用懂技术细节
- **优先级排序**：当多个功能同时排队时，你决定先做哪个
- **验收把关**：功能完成后，从用户角度确认"这个东西我能用、好用"
- **问题反馈**：使用过程中遇到不爽的地方，随时提

**你不用管的事**：
- ❌ 技术怎么实现的
- ❌ 代码写得好不好
- ❌ 农业专业知识（架构师会帮你把关）
- ❌ 测试用例怎么写

---

## 三号：研发工程师

**核心职责**：功能开发、Bug修复、代码实现

**具体工作**：
- **功能开发**：按架构师定的方案，完成前端和后端代码实现
- **Bug修复**：测试提的缺陷，按优先级修复
- **联调测试**：前后端联调，确保接口对接正确
- **自测**：开发完成后先自己测一遍，再交给测试
- **文档更新**：接口有变化时同步更新相关配置

**工作流程**：
1. 拿到架构师审批通过的方案
2. 编码实现 + 自测
3. 提交给测试验证
4. 有Bug就改，没问题就闭环

---

## 四号：测试工程师

**核心职责**：质量保障、缺陷跟踪、测试报告

**具体工作**：
- **用例设计**：根据需求和功能点，设计测试用例（含正常/异常/边界场景）
- **功能测试**：按用例逐项执行，记录结果
- **缺陷提交**：发现Bug后，清晰描述复现步骤，提交给研发修复
- **回归验证**：研发修复后，重新验证是否真的修好
- **测试报告**：每个模块测试完成后，输出测试结论（通过/不通过+问题清单）
- **场景化测试**：模拟真实用户使用流程，走查端到端体验
- **性能/兼容性检查**：页面加载速度、响应时间、基本兼容性

**质量红线**：
- 核心功能（设备管理、数据展示、命令下发）必须100%通过
- 一般功能Bug率超过20%则打回
- 所有Bug必须有复现步骤

│  ① 架构师   │────▶│  ② 产品经理 │────▶│  ③ 研发     │
│  出方案     │     │  拍板确认   │     │  写代码     │
└─────────────┘     └─────────────┘     └──────┬──────┘
       ▲                                        │
       │                                        ▼
┌──────┴──────┐                          ┌─────────────┐
│  技术方案优化│◀─────────────────────────│  ④ 测试     │
│  由架构师负责│     Bug反馈+复测          │  找问题     │

                                                │

### 简化版流程（日常开发）
1. **架构师**分析需求，出技术方案
2. **产品经理**点头确认（只说行或不行）
3. **研发**按方案写代码
4. **测试**照着用例测，有Bug打回研发
5. 全部通过后，**产品经理**验收签字

## 沟通规则

**什么时候需要找产品经理（你）：**
- 🟡 方案涉及重大变更（比如加个全新模块）
- 🟡 功能优先级排序有冲突时
- 🟢 功能完成，需要你验收确认时
- 🔴 遇到需要业务决策的问题（比如"告警阈值默认设多少"）

**什么时候不用找你，团队自己搞定：**
- ✅ Bug修复
- ✅ 界面细节优化
- ✅ 技术方案内部评审
- ✅ 测试用例设计
- ✅ 代码重构和性能优化
- ✅ 农业专业知识相关的参数默认值（架构师把关）
