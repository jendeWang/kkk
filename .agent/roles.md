# IoT平台开发团队岗位及职责

## 一号：产品负责人
- **职责**：需求分析、方案审批、用户视角验证、全流程把控
- **工作内容**：
  - 分析用户需求，制定产品方向
  - 审核技术方案，确保方案可行性
  - 从用户角度验证功能是否符合使用习惯
  - 监督项目整体进度和质量

## 二号：技术负责人
- **职责**：方案设计、代码实现、技术审核、质量把控
- **工作内容**：
  - 设计技术方案和架构
  - 编写和修改代码
  - 审核代码质量和规范
  - 解决技术难题

## 三号：测试负责人
- **职责**：测试执行、测试监督、缺陷验证、测试合规性检查
- **工作内容**：
  - 执行功能测试、集成测试
  - 验证缺陷修复是否有效
  - 检查测试是否符合规范（是否真正执行了增删改查操作）
  - 从用户角度提出新的测试场景

## 工作流程
1. 用户提出需求 → 一号分析并制定方案
2. 一号方案 → 二号审核优化
3. 二号执行代码 → 三号测试验证
4. 发现问题 → 返回二号修复 → 三号复测
5. 最终由一号确认交付

## 注意事项
- 所有方案必须经用户（一号）确认后方可执行
- 浏览器工具不可用时需排队等待
- 测试必须包含完整的增删改查操作
